# Slice 4 — expected early-start loss on a recorded conversation

**Claim to prove.** Calibrate a threshold on held-out recordings. Bound the expected fraction of eligible turns where the proposed speaking start precedes the annotated completion in a new exchangeable conversation. The distribution averages over calibration and the new conversation, giving conversations equal weight. A recorded completion time is a fixed outcome in this experiment.

1. Fix an ordered finite grid of policies and an eligibility rule before calibration. For each eligible turn t define its reference completion eₜ and proposed start dₜ(λ), including an abstain value later than every completion. Require the proposed start to move weakly later as λ increases, and the last policy to abstain. Define L(c,λ) as the mean of 1{dₜ(λ) < eₜ} over a conversation's eligible turns. Set L = 0 for an empty eligible set and state that those conversations remain in the deployment population. Prove 0 ≤ L ≤ 1, antitonicity in λ, and zero loss at the last policy.
2. Specialize `crcRule` with B = 1. Its corrected calibration inequality at a threshold is (1 + sum of the G calibration losses)/(G+1) ≤ α. If no empirical threshold is feasible the rule takes the last policy. Use `crc_orderings` and the invariant-law averaging argument from [slice 1](01-conversation-band-brief.md) to prove E[L(new conversation, selected policy)] ≤ α. The deployed policy can use only the allowed observed prefix to decide when to start. Reference completions are used to score its recorded decisions.
3. Test the denominator. Give two eligible turns and two ordered policies. Under the first policy one start is early and the other on time. Under the second the early start remains and the on-time start becomes an abstention. Compute the eligible-turn loss at both policies and show that the early fraction among actual starts rises from 1/2 to 1. Include the all-abstain and empty-conversation cases.

**Acceptance.** Verify the loss properties, threshold rule, population expectation and denominator witness. State the time convention at equality and the sampling unit. A high-confidence assertion over calibration sets, a bound on each conversation, and the effect of speaking on a live partner's completion would each require a different argument.
