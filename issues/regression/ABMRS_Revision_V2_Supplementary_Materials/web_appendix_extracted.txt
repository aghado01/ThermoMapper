B Web Appendix B
For curve fitting, the proposed method is benchmarked against Bayesian Adaptive Knot Regression
Splines (BARS) (Dimatteo et al., 2001), Smoothing Splines (SMS) (Green and Silverman, 1994),
and Gaussian Process Regression (GPR) (Rasmussen and Williams, 2005). BARS is a Bayesian
method for knot estimation in univariate splines, which employs a Poisson prior for the number of
knots. However, this method cannot be directly extended to multivariate splines. SMS represents a
class of penalized splines that incorporate a roughness penalty. It models the unknown function as
a spline with a large number of knots, enabling a high degree of flexibility, while the roughness
penalty regulates the smoothness of the spline. SMS is implemented using the build-in funtion
smooth.spline, and GPR with the squared exponential kernel is implemented using the R package
GauPro (Erickson, 2025).
We examine three curves with varying levels of smoothness, labeled as Curves 1–3. The output
noise follows a Gaussian distribution with standard deviations of 2, 4, and 1 for Curves 1, 2, and 3,
respectively. Web Figure 1 depicts the curves along with the training samples. Curve1 is continuous,
whereas Curves 2 and 3 exhibit discontinuities with one or more jump breakpoints.
To investigate the influence of the parameter γ in the proposed method, we consider three scenarios
where γ is set to 0.8, 1.0, and 1.2. All methods are evaluated under sample sizes m = 200and 500,
with the experiment repeated 50 times. Prediction performance is assessed using the Root Mean
Squared Error (RMSE).
Web Figure 1: Curve fitting with sample size m = 200. Rows correspond to Curves 1–3 (top to
bottom). Columns correspond to the ground truth with noisy samples (red points), followed by
estimates using ABMRS (with γ ∈ {0.8, 1.0, 1.2}), BARS, SMS, and GPR (left to right).

The fitted curves are shown in Columns 2–6 of Web Figure 1, and the RMSEs are summarized
in Web Table 1. For the smooth curve (Curve1), all methods achieve low RMSEs. However, for
the discontinuous curves (Curves 2 and 3), SMS and GPR fail to capture the jump discontinuities,
resulting in substantially degraded performance. The BARS method performs well when the true
number of knots is relatively small. However, for highly oscillatory true functions (Curve 3), BARS
tends to include too few knots in its estimation. In this example, the proposed method with γ = 1.2
yields a high RMSE for Curve 3 when the sample size is m = 200, indicating that γ >1 can lead
to overly regularized models for highly oscillatory curves. This issue can be substantially alleviated
by choosing a smaller value of γ or increasing the sample size.

We compare the proposed method with Thin Plate Regression Splines (TPRS) (Wood, 2003), Tensor
Product Regression Splines (TEPS) (Wood, 2017), Bayesian MARS (BMARS) (Denison et al.,
1998), and Gaussian Process Regression (GPR) (Rasmussen and Williams, 2005). Both TPRS and
TEPS extend smoothing splines to multivariate settings using prespecified knots. We implement
TPRS and TEPS using the R package mgcv with a roughness penalty (Wood and Wood, 2015).
BMARS is implemented using the R package BASS (Francom and Sansó, 2020), and GPR with the
Matérn kernel is implemented using the R package GauPro (Erickson, 2025). For BMARS, we
consider spline degrees 1, 2, and 3, and report the best results.
In this example, we employ cubic splines and consider γ ∈ {0.8, 1.0, 1.2} in the proposed method.
All methods are evaluated under sample sizes m = 250and 1000, with the experiment repeated 50
times. Model performance is assessed using the Root Mean Squared Error (RMSE). To evaluate
predictive uncertainty, we construct prediction intervals for the true functions and compare the
average coverage and interval widths across methods.
Web Table 2 reports the results for the additional surface fitting problem. All methods achieve low
RMSEs across all scenarios, with RMSEs decreasing as the sample size increases. When evaluating
predictive uncertainty, all compared methods achieve an empirical coverage for their prediction
intervals that matches the nominal confidence level. The credible or confidence intervals for the
mean function—which exclude noise variance—tell a slightly different story. Here, our proposed
method yields moderately lower coverage than TPRS, TEPS, and GPR. Even so, it stays within a
reasonable range, unlike BMARS, which suffers from consistently poor coverage across every case.
Finally, the proposed method proves highly robust to the choice of γ, showing very similar results
across different values.
D Web Appendix D
Web Table 3 reports the additional results about predictive uncertainty in Section 4.2.1. When
evaluating the coverage of 95% credible (confidence) intervals for the mean function, the proposed
method achieves moderately lower, yet still reasonable, coverage compared to TPRS, TEPS, and
GPR. This difference is expected: TPRS, TEPS and GPR rely on frequentist interval construction
and therefore enjoy nominal frequency guarantees, whereas the proposed method is fully Bayesian
and constructs confidence intervals using posterior quantiles, which do not provide exact frequentist
coverage. BMARS, by contrast, attains consistently poor coverage across all surfaces.
